# qbook

Терминальная читалка для EPUB и текста (Rust + ratatui) в интерфейсе btop:
панели в рамках, метрики в заголовке, клавиатурный бар снизу. Богатый текст из
EPUB — жирный, курсив, ссылки, списки, цитаты, картинки прямо в потоке
полублоками. Синхронное переключение языка сохраняет позицию чтения; перевод
книги — из коробки: локальный сервер или LLM, прогресс, resume после сбоя.

## Быстрый старт

```sh
nix build && ./result/bin/qbook demo/moon.epub   # сборка + демо с переводом
qbook путь/к/книге.epub                          # читалка: epub, txt
qbook                                            # без пути — полка книг
```

Перевод книги на ещё один язык (нужен локальный сервер — LibreTranslate или
OpenAI-совместимый LLM, см. ниже):

```sh
qbook translate книга.epub ru     # книга.ru.epub рядом с исходником
qbook книга.epub                  # открыть: переводы подхватываются клавишей t
```

Книга с картинками и форматированием — прямо в терминале; перевод накатывается
на ту же разметку, жирный/курсив/ссылки живут и в `книга.ru.epub`.

## Установка

Nix (бинарник в `./result`):

```sh
nix build
./result/bin/qbook --version
```

cargo (в профиль):

```sh
cargo install --path .          # перевод включён по умолчанию
```

## Релизы

Собранный бинарник для Linux — в [GitHub Releases](https://github.com/axstiz/Qbook/releases):
`qbook-v0.2.0-x86_64-unknown-linux-gnu.tar.gz`. Сборка идёт автоматически при
теге `v*`; каждый коммит проверяют CI: `cargo fmt --check`, `clippy -D warnings`,
`cargo test --all-targets`.

## Читалка

```
qbook book.epub          # текст в колонке, картинки полублоками, t — перевод
qbook book.txt           # plain-текст, пустая строка = граница абзаца
qbook book.epub --lang ru --variant en=../en/book.en.txt
```

Формат `.md` не поддерживается: открывайте epub или txt. Сайдкары перевода
находятся автоматически: `книга.<lang>.{epub,txt}` рядом с книгой — один
вариант на язык; при нескольких файлах побеждает файл с тем же расширением,
что и исходник. Явные файлы — `--variant LANG=PATH` (можно несколько раз).

Язык исходника — `--lang` (без флага: имя файла `book.ru.*`, метаданные EPUB,
AUTO по тексту). Позиция чтения хранится якорем `(блок, доля)` в базовых
координатах, поэтому смена языка не двигает страницу. Выравнивание абзацев —
banded Needleman–Wunsch с быстрым путём; кэш выравнивания — в SQLite.

## Перевод книги

`qbook translate` переводит целый EPUB и кладёт результат рядом сайдкаром
`книга.<lang>.epub`. Меняются только текстовые узлы (тело книги и оглавление
`nav`/`ncx`); разметка, стили, картинки и OPF сохраняются байт-в-байт.

Два движка (выбирайте `--engine`):

```sh
# LibreTranslate (Argos Translate, CPU, без GPU) — по умолчанию
pip install libretranslate && libretranslate --load-only en,ru
qbook translate книга.epub ru --server http://localhost:5000

# OpenAI-совместимый бэкенд: ollama / llama.cpp / LM Studio
ollama serve             # модель llama3 по умолчанию
qbook translate книга.epub ru --engine ollama --model llama3
```

Полезные флаги:

```sh
--dry-run                # план: юниты, документы, обращения к серверу
--check                  # доктор окружения: книга, язык, сервер — по строчке
--batch N                # текстов в одном запросе (32 — libre, 8 — ollama)
--jobs N                 # документов в параллели
--output путь.epub       # имя результата (по умолчанию сайдкар рядом)
```

Перевод журналируется: каждый переведённый юнит (блочный элемент) отмечается
в SQLite, прерванная задача возобновляется автоматически — повторный запуск
той же команды с той же книгой/языком/движком продолжает с места сбоя и
частями не пересылает готовое. Прогресс печатается на stderr
(`переведено 120/340 юнитов`).

То же самое — прямо из читалки: `:translate ru` запускает фоновую задачу,
внизу живёт панель прогресса, по завершении тост и свежий сайдкар сразу
доступен клавишей `t`. Сервер/движок берутся из конфига:

```toml
[defaults]
engine = "libre"                          # или "ollama"
server = "http://localhost:5000"          # адрес сервера
model = "llama3"                          # для ollama
```

## Раскладка клавиш

Читалка — трёхколоночная btop-оболочка: шапка книги над блоками, слева «Главы»,
по центру текст в рамке с метриками (градиентный прогресс-бар), справа
«Заметки»·«Команды»; внизу — слот тостов/панели перевода и клавиатурный бар.
`h` — справка в модальном окне. Текст у нижнего края плавно гаснет
градиентом (`fade_text = false` отключает).

| Клавиши | Действие |
| --- | --- |
| `j` `k` `↓` `↑` | строку вниз / вверх |
| `Space` `PgDn` / `PgUp` | страница вниз / вверх |
| `Ctrl+D` `Ctrl+U` | полстраницы вниз / вверх |
| `g` `G` | к началу / к концу |
| колесо мыши | прокрутка на `wheel_lines` строк (по умолчанию 3) |
| `1…4` | фокус: текст / главы / заметки / команды |
| `Shift+1…4` (`!` `@` `#` `$`) | показать/скрыть блок (Shift+1 — только текст ⇄ все колонки) |
| `t` | следующий язык (позиция сохраняется) |
| `b` | заметка: `↑/↓` — строка, `Enter` — метка, `c`/`C` — цвет |
| `v` | выделение: якорь, `↑/↓` тянут, `Enter`/`y` — копировать (OSC 52) |
| `n` `p` | следующая / предыдущая закладка |
| `/` | поиск: `Tab` — режим (текст → заметки → главы), `Enter` — прыжок |
| `h` `?` | справка (`Esc` закрывает) |
| `[` `]` | уже / шире колонку (позиция сохраняется) |
| `S` | на полку |
| `Q` `Ctrl+C` | выход |

`S` и `Q` работают из любого блока, их подсказка живёт в правом верхнем углу
(`S полка · Q выход`). На полке: `j`/`k`, `Enter` — открыть, `a` — добавить
книгу (ввод пути), `d` — удалить, `Q` — выход.

## Команды

Ввод — `:` (или `5`); список полезных — блок «Команды» справа.

| Команда | Действие |
| --- | --- |
| `open <путь>` | открыть книгу по пути |
| `lang t` / `lang <код>` | следующий язык / по коду |
| `translate <lang> [сервер]` | запустить перевод книги в сайдкар |
| `goto <N>` | перейти к блоку N |
| `toc` / `notes` / `panels` | показать/скрыть блоки |
| `wider` / `narrower` | шире / уже колонку |
| `theme list` / `theme set <имя>` / `theme save` | список, смена, запись темы |
| `help` | справка по клавишам |
| `shelf` | на полку |
| `b` | закладка на текущей позиции |
| `q` | выход |

Неизвестная команда, несуществующий язык/блок или недоступное окружение —
тост-ошибка.

## Конфигурация

Файл `$XDG_CONFIG_HOME/qbook/config.toml` либо путь из `QBOOK_CONFIG`.
Без файла действуют встроенные значения; битый TOML и нарушенный цвет
— ошибка при старте. Пресет темы — флаг `--theme btop|mono|light`, поля файла
перекрывают пресет.

```toml
[defaults]
wheel_lines = 3        # строк на прокрутку колесом
toc = true             # колонки видны при первом открытии
bookmarks = true
commands = true
column_extra = 0       # стартовое смещение ширины колонки ([ / ])
fade_text = true       # гасить текст у нижнего края
images = "half"        # half — полублоки в тексте, off — только alt-текст
engine = "libre"       # движок :translate — libre | ollama
server = "http://localhost:5000"   # адрес сервера перевода
model = "llama3"       # модель для ollama

[theme]
key = "yellow"
gauge_start = "#5a1e8c"
notes = ["red", "green", "yellow", "blue", "magenta", "cyan", "white"]
```

Цвет — имя (`black`… `white`, `lightred`…) или hex `#rrggbb`/`#rgb`. Роли
(`[theme]`): `key` — клавиши бара и курсоры, `accent` — подсказки предела и
ошибки, `dim` — неактивные рамки и хвост, `active` — активная рамка, `heading`
— открытая глава в оглавлении, `notice` — тосты, `selection_bg` — фон
выделения, `rule` — линия `---`, `gauge_start`/`gauge_end`/`gauge_empty` —
градиент прогресса, `notes` — семь цветов заметок.

Пресеты: `btop` (по умолчанию), `mono` (монохром), `light` (светлый фон).
Смена — `:theme set mono`, запись выбранного — `:theme save`.

Шапка книги: название, позиция `блок/всего`, метка заметки на текущем блоке.
В заголовке рамки текста — языки `en▸ru`, градиентный прогресс и процент.
В списках `j`/`k` — курсор, `Enter` — действие, `Esc` — к тексту; в заметках
`r` — переименовать, `c`/`C` — цвет, `D` — удалить. На узких терминалах
сначала прячется правая колонка, затем левая.

## Хранилище

SQLite в `$XDG_DATA_HOME/qbook/qbook.db`. Миграции через
`PRAGMA user_version` (текущая версия — 4).

| Таблица | Назначение |
| --- | --- |
| `books` | каталог книг: путь, заголовок, базовый язык, даты, размер |
| `variants` | файлы переводов: `(book_id, lang)` → путь, формат |
| `progress` | позиция чтения: якорь `(block, frac)`, язык, процент |
| `bookmarks` | закладки: якорь, метка, дата, цвет |
| `alignments` | кэш выравнивания: пара хешей → карта блоков и покрытие |
| `translate_jobs` | задачи перевода: книга, языки, движок, штамп |
| `translate_units` | юниты задач: документ#индекс → pending/done/failed |

Книги удаляются каскадно (`ON DELETE CASCADE`).

## Демо и метрики

В `demo/` лежит пара EPUB (`moon.epub` + `moon.ru.epub`) с одинаковой
структурой абзацев:

```sh
qbook demo/moon.epub          # t — абзац не должен прыгать, o — оглавление
cargo test --test demo        # структура пары и TOC обоих EPUB
cargo test --test perf        # пороги: открытие ≤ 300 мс, кадр ≤ 5 мс
cargo test --test translate   # resume после обрыва на середине книги
```
