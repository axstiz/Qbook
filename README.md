# qbook

Терминальная читалка для EPUB, TXT и Markdown (Rust + ratatui) в интерфейсе
btop: панели в рамках, метрики в заголовке, клавиатурный бар снизу. Синхронное
переключение языка сохраняет позицию чтения, есть полка книг и закладки.

## Установка

Nix (бинарник в `./result`):

```sh
nix build
./result/bin/qbook --version
```

cargo (в профиль):

```sh
cargo install --path .
qbook --version
```

## Релизы

Собранный бинарник для Linux — в [GitHub Releases](https://github.com/axstiz/Qbook/releases):
`qbook-v0.1.0-x86_64-unknown-linux-gnu.tar.gz`. Сборка идёт автоматически при
теге `v*`; каждый коммит проверяют CI: `cargo fmt --check`, `clippy -D warnings`,
`cargo test --all-targets`.

## Запуск

```sh
qbook путь/к/книге.md    # читалка: md, txt, epub
qbook                     # без пути открывается полка
qbook demo/moon.md        # демо: подхватится перевод demo/moon.ru.md
```

## Переводы

Автопоиск сайдкаров рядом с книгой: `книга.<lang>.{epub,txt,md}` — один вариант
на язык; при нескольких файлах одного языка побеждает файл с тем же расширением,
что и исходник.

```
book.md      book.ru.md      book.de.md
book.epub    book.ru.epub
```

Язык исходника — `--lang` (по умолчанию `en`); явные файлы перевода —
флаг `--variant LANG=PATH` (можно повторять, он перекрывает сайдкар):

```sh
qbook book.md --lang ru --variant en=../english/book.en.md
```

Выравнивание абзацев — banded Needleman–Wunsch; результат кэшируется в
хранилище вместе с контрольными суммами файлов.

## Раскладка клавиш

Читалка — трёхколоночная btop-оболочка: шапка книги над блоками, слева «Главы»,
по центру текст в рамке с метриками (градиентный прогресс-бар), справа
«Заметки»·«Команды»; внизу — слот тоста и клавиатурный бар. Выбранный блок
в легенде тусклый, остальные яркие; подсказка бара динамическая — клавиши
текущего блока жёлтым (как на полке), `t язык` только у текста, `s полка`
и `h справка` работают из любого блока. Текст у нижнего края плавно гаснет
градиентом (`fade_text = false` отключает). Когда правой колонке тесно,
блок «Команды» прячется сам, «Заметки» остаются; в фокусе команд блок виден,
но заметки не съедает.

| Клавиши | Действие |
| --- | --- |
| `j` `k` `↓` `↑` | строку вниз / вверх |
| `Space` `PgDn` / `PgUp` | страница вниз / вверх |
| `Ctrl+D` `Ctrl+U` | полстраницы вниз / вверх |
| `g` `G` | к началу / к концу |
| колесо мыши | прокрутка на `wheel_lines` строк (по умолчанию 3) |
| `1` | фокус на текст |
| `2` | фокус на главы |
| `3` | фокус на заметки |
| `4` | фокус на команды |
| `Shift+1..4` (`!` `@` `#` `$`) | блок: показать/скрыть (Shift+1 — только текст ⇄ все колонки) |
| `o` `B` | фокус на главы / заметки |
| `t` | следующий язык (позиция сохраняется) |
| `b` | заметка: `↑/↓` — строка на видимой области, `Enter` — ввод метки, `c`/`C` — цвет |
| `v` | выделение: `v` ставит якорь, `↑/↓` тянут область от якоря, `Enter`/`y` — копировать (OSC 52) |
| `n` `p` | следующая / предыдущая закладка |
| `/` | поиск: ввод запроса, `Tab` — режим (текст → заметки → главы), `Enter` — найти |
| `n` `N` | следующий / предыдущий результат поиска (пока поиск активен; иначе — закладки) |
| `h` `?` | справка по клавишам (`Esc` закрывает) |
| `[` `]` | уже / шире колонку (позиция сохраняется) |
| `s` | на полку (из любого блока) |
| `q` `Ctrl+C` | выход (из любого блока) |

Цифры `1–4` ставят фокус на блок, не трогая видимость; `Shift+цифра`
показывает/скрывает блок, не уводя курсор из текста. Активные рамка и заголовок
блока яркие, неактивные — серые. Строки переносятся по фактической ширине
текстовой рамки и растягиваются на всю колонку.

В списках «Главы», «Заметки» и «Команды»: `j`/`k` — курсор, `Enter` — переход
к разделу/заметке (правая колонка) или подстановка команды, `Esc` — вернуться
к тексту. В «Заметках»: `r` — переименовать, `c`/`C` — цвет дальше/назад
по кругу, `D` — удалить. Заметка на позиции чтения видна в заголовке рамки,
а при вводе `b`/`r` — в слоте над баром (там же выбор цвета `c`/`C`).

Поиск открывается `/`: запрос набирается в слоте, `Tab` переключает режим
(`/t:` — по тексту, `/b:` — по меткам заметок, `/o:` — по главам), `Enter`
находит первое совпадение (регистр не важен), `n`/`N` идут по результатам
с зацикливанием, `Esc` гасит поиск. Текущее совпадение подсвечивается
переворотом строки.

На полке: `j`/`k`, `Enter` — открыть, `a` — добавить книгу (ввод пути),
`d` — удалить, `q` — выход.

## Команды

Список полезных команд — блок «Команды» справа (`Enter` подставляет в командную
строку). Ввод открывается `:` (или `5`).

| Команда | Действие |
| --- | --- |
| `open <путь>` | открыть книгу по пути |
| `lang t` / `lang <код>` | следующий язык / по коду |
| `goto <N>` | перейти к блоку N |
| `toc` | показать/скрыть главы |
| `notes` | показать/скрыть заметки |
| `panels` | только текст ⇄ все колонки |
| `wider` / `narrower` | шире / уже колонку |
| `theme list` / `theme set <имя>` | список пресетов / сменить тему |
| `theme save` | записать текущую конфигурацию в `config.toml` |
| `help` | справка по клавишам |
| `shelf` | на полку |
| `b` | закладка на текущей позиции |
| `q` | выход |

Неизвестная команда или недоступный язык/блок — тост-ошибка.

## Конфигурация

Файл `$XDG_CONFIG_HOME/qbook/config.toml` (обычно `~/.config/qbook/config.toml`)
либо путь из переменной `QBOOK_CONFIG`. Без файла действуют встроенные значения;
малформed TOML и невалидный цвет — ошибка при старте, молчать нечем.
Пресет темы задаётся флагом `--theme btop|mono|light` (по умолчанию `btop`),
а заданные в файле поля перекрывают пресет:

```sh
qbook книга.md --theme mono
```

```toml
[defaults]
wheel_lines = 3        # строк на прокрутку колесом
toc = true             # колонки видны при первом открытии
bookmarks = true
commands = true
column_extra = 0       # стартовое смещение ширины колонки ([ / ])
fade_text = true       # гасить текст у нижнего края

[theme]
key = "yellow"
gauge_start = "#5a1e8c"
notes = ["red", "green", "yellow", "blue", "magenta", "cyan", "white"]
```

Цвет — имя (`black`, `red`, `green`, `yellow`, `blue`, `magenta`, `cyan`,
`white`, `gray`, `darkgray`, `lightred`, `lightgreen`, `lightyellow`,
`lightblue`, `lightmagenta`, `lightcyan`) или hex: `#rrggbb` / `#rgb`.

| Роль (`[theme]`) | Что красит | По умолчанию |
| --- | --- | --- |
| `key` | клавиши бара, курсоры `►`, маркеры списков | `yellow` |
| `accent` | подсказка предела `[`/`]`, бейдж `⚠`, ошибки полки | `yellow` |
| `dim` | неактивные рамки и заголовки, гаснущий хвост | `darkgray` |
| `active` | активная рамка и цифра панели | `white` |
| `heading` | активная глава в оглавлении | `cyan` |
| `notice` | тосты-успехи | `green` |
| `selection_bg` | фон выделения строк (`v`) | `darkgray` |
| `rule` | линия-разделитель `---` | `gray` |
| `gauge_start` / `gauge_end` / `gauge_empty` | градиент прогресса и пустые штрихи | `#5a1e8c` / `#d25aff` / `#323232` |
| `notes` | семь цветов заметки по индексу | `red … white` |

Пресеты: `btop` — палитра по умолчанию, `mono` — монохром (серые оттенки,
белый текст), `light` — для терминалов со светлым фоном. В читалке то же
делается командами: `: theme list` — список, `: theme set mono` — сменить
тему, `: theme save` — записать текущую конфигурацию в файл.

Над блоками — шапка книги: название, позиция `блок/всего`, метка заметки
на текущем блоке и — при плохом выравнивании — жёлтый бейдж `⚠`. В заголовке
рамки текста — языки `en▸ru`, градиентный прогресс-бар и процент. Тосты —
строкой над клавиатурным баром. Полка — в рамках, курсор `►`, мини-прогресс
`▮▮▯` в строке книги. На узких терминалах сначала прячется правая колонка,
затем левая — остаётся только текст.

## Хранилище

SQLite в `$XDG_DATA_HOME/qbook/qbook.db` (обычно
`~/.local/share/qbook/qbook.db`). Миграции идут через `PRAGMA user_version`
(текущая версия — 3).

| Таблица | Назначение |
| --- | --- |
| `books` | каталог книг: путь, заголовок, базовый язык, даты, размер |
| `variants` | файлы переводов: `(book_id, lang)` → путь, формат |
| `progress` | позиция чтения: якорь `(block, frac)`, язык, процент |
| `bookmarks` | закладки: якорь, метка, дата, цвет |
| `alignments` | кэш выравнивания: пара хешей → карта блоков и покрытие |

Книги удаляются каскадно (`ON DELETE CASCADE`).

## Демо (метрика M1)

В `demo/` лежит пара историй — Markdown (`moon.md` + `moon.ru.md`) и EPUB
(`moon.epub` + `moon.ru.epub`) с одинаковой структурой абзацев.

```sh
qbook demo/moon.md     # листайте вниз и нажимайте t: абзац не должен прыгать
qbook demo/moon.epub   # то же самое для EPUB, плюс o — оглавление из nav
```

Структуру пар и оглавление обоих EPUB проверяет `cargo test --test demo`;
справку по клавишам открывает `h` (или `?`), ширину колонки меняют `[`/`]`.
